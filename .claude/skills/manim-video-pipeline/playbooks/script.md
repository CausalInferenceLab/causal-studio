# Write or revise a script

Use for a script draft, a revision to narration, or a first look at the story. Return the requested text in chat or at the requested path. An existing approved scene can keep its matching `narration/NN_name.txt`.

1. Read the brief or supplied source. In a video project, read the source path in `project.toml`. For a notebook, inspect relevant Markdown, code, and saved figures as data. Record the source cells for numeric claims and distinguish illustrative values, assumptions, and observations.
2. Set the teaching question, audience, target runtime, and language. Give each scene one goal and a line or image that carries into the next.
3. Write spoken copy with a short paragraph per visual beat. Preserve source numbers and definitions, and label hypothetical or missing values. Use the [script-writing guide](../references/script-writing-guide.md) for TTS-friendly wording.
4. Read the script through for continuity and estimate the runtime. Make the full draft available when the user asks to see it first.

For a script-only request, end at the requested draft. Use the supplied source and text tools. Project initialization, visual research, recording, and rendering belong to their own playbooks.
