# Study references and design a visual passage

Use for reference research, storyboard work, or a prototype. Deliver the requested level of detail. A reference-only request ends with the timestamped passage, code link, and applicable visual choice. A storyboard request ends with the planned visual beats. Render a prototype when the user asks to see motion or the full-video playbook calls for one.

1. **Find the visual idea.** Choose a concrete example and one subject the viewer can follow. Sketch the opening, the revealing movement, and the held result before adding text.
2. **Trace a 3Blue1Brown passage.** Start with a supplied clip, then look for a passage that solves the same visual problem. Inspect the full frame at the setup, move, and hold. Record the timestamp, relevant Manim source, and what the framing, scale, color, negative space, labels, and pacing do for the explanation. Identify related source separately when the exact scene code cannot be found. If playback is unavailable, try an official playable alternative and record the limitation. See [reference study](../references/manim-code-patterns.md#reference-study-and-adaptation).
3. **Storyboard the change.** Carry a visible anchor across beats. State where the camera lands and what the change in view reveals. Keep dense comparisons steady and hold the payoff. Use local labels and leave corners open. Check [camera movement](../references/manim-code-patterns.md#camera-movement-and-reframing) and [caption clearance](../references/manim-code-patterns.md#layout-and-caption-safe-area). Record the decisions in the [scene plan](../templates/scene_plan.md) when working on a video project.
4. **Test the prototype when requested.** Use the [single-scene playbook](scene.md) to render the opening, hardest move, and hold with provisional timing. Watch it muted at normal speed in the target aspect ratio. Use the [review playbook](review.md) to inspect key frames. Revise the move if the subject is hard to track or a label has to explain a relationship the picture should show.

Use `bash scripts/setup_video_assets.sh --ensure` when a task needs local 3Blue1Brown source or Tabler SVGs. Use only icons that communicate something the viewer needs. Credit adapted code and assets and check their licenses. See [Manim visual patterns](../references/manim-code-patterns.md).
