# Produce a full video

Use for end-to-end video requests. Honor interim deliverables such as “show the script and one prototype first.” At that checkpoint, hand over the draft and prototype before producing the remaining scenes.

## Assign the work

The lead owns the full script, `scene_plan.md`, shared style and voice, and final edit decisions. Use specialist agents for full-video work when the host supports delegation and follow the user's delegation preferences. Give each agent the relevant playbook, source, audience, and exact output. Assign editing agents distinct files. When delegation is unavailable, run the same passes sequentially and report how the review was performed.

| Role | Input and handoff |
|---|---|
| Script and source | Read the source and draft the story. Return narration, estimated scene lengths, and source cells or references for key claims and assumptions. |
| Reference and visual design | Study a relevant 3Blue1Brown passage and its code. Return the timestamp, code permalink, visual plan, and decisions that must carry across scene boundaries. |
| Scene producers | Use the shared design and measured timing. Each producer owns assigned scene files and returns the render path, length, log, and any issue that affects a neighboring scene. |
| Independent reviewer | Review the prototype and assembled cut without implementation context on the first pass. Return time-coded readability, continuity, and accuracy findings. |

## Run the stages

1. Start [script](script.md) and [visual design](visual-design.md) together once the source and teaching question are clear. Merge them into the full story and storyboard. Resolve disagreements about figures and observed versus hypothetical values before recording.
2. Scope a silent prototype to the most important transition. Have the reviewer watch it using the [review playbook](review.md). Add a short narrated sample if voice or sync needs an early check. Follow the user's approval cadence.
3. Once the script and design are ready and the requested checkpoint is satisfied, record by scene through [audio and sync](audio-sync.md) for a narrated video. Hand each producer the matching MP3 and timing file. Use the [single-scene playbook](scene.md) for individual previews. Run independent scenes in parallel and coordinate scenes that share an anchor or camera move.
4. Assemble a low-quality cut with the intended audio and review the entire video before final renders. Repair the affected scenes and recheck neighboring cuts. Then render at delivery quality, [package](package.md), and review the final playback and [captions](captions.md).

Deliver the requested MP4, thumbnail, and SRT when narrated, with the source and script paths when useful. Briefly describe the visual reference applied and any viewing limitation. See the [ten-minute lesson example](../references/long-form-production.md).
