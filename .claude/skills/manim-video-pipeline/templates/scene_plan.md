## Visual direction

- **Composition** — Sketch the opening example, main movement, and held result before adding text. Name the object that carries through each scene boundary and where it appears in the next shot.
- **Camera, when it moves** — Record the anchor, starting view, where the anchor lands, and the new relationship the view reveals. Mark where the view settles and the viewer gets time to look.
- **Palette and contrast** — Assign roles to background, supporting marks, main objects, and emphasis. Keep the roles consistent as the frame changes.
- **On-screen text** — For every planned label or formula, name its object or purpose, when it appears, and when it leaves. Keep the corners clear by default.
