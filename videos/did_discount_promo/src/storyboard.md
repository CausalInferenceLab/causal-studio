# 할인 기획전 영상, 대본과 화면 대응

모든 수치는 교육용 가상 수치다. 참여군과 대조군은 각각 매장 100곳이다. 진행 전후 비교는 2주 합계이고, 사전 추세와 반사실 그래프는 주별 예약이다.

| 시각 | 내레이션 | 화면 변화 |
| --- | --- | --- |
| 0:00–0:07 | 할인 기획전이 진행된 2주 동안, 참여 매장 100곳에서 예약이 1만 2천 건 들어왔습니다. | 실제 예약 12,000건 한 숫자 등장 |
| 0:07–0:13 | 직전 2주보다 2천 건 많지만, 그만큼이 전부 기획전 효과는 아닙니다. | 12,000을 지우고 관찰된 증가 +2,000건, 효과와 구분 |
| 0:13–0:19 | 효과를 알려면 기획전이 없었을 때 예약이 얼마였을지 추정해야 합니다. | 빈 반사실 예약을 질문으로 제시 |
| 0:19–0:22 | 직전 2주 예약은 1만 건이었습니다. | 0부터 시작하는 2주 합계 축에 10,000 막대 |
| 0:22–0:25 | 2천 건이 늘어난 건 사실입니다. | 같은 축에 진행 2주 막대와 +2,000 |
| 0:25–0:31 | 하지만 계절이나 서비스 전체 수요가 같은 기간 예약을 늘렸을 수도 있습니다. | 계절 / 서비스 전체 수요 문구, 두 막대 약하게 |
| 0:31–0:35 | 전후 숫자만으로는 그 몫을 구분할 수 없습니다. | 관찰된 증가 ≠ 기획전 효과 |
| 0:35–0:40 | 기획전에 참여하지 않은 대조군도 100곳으로 맞춘 가상 예시입니다. | 참여 100곳 / 대조군 100곳, 같은 눈금의 참여군 선 |
| 0:40–0:45 | 대조군 예약은 같은 2주에 8천 건에서 9천 건으로 늘었습니다. | 같은 축에 대조군 선 추가 |
| 0:45–0:50 | 기획전이 없어도 생겼을 변화가 1천 건 보입니다. | 대조군도 +1,000건 강조 |
| 0:50–0:56 | 대조군을 믿으려면, 기획전 전에도 두 집단이 비슷하게 움직였는지 살펴야 합니다. | 좋은 대조군인가? |
| 0:56–1:01 | 기획전 전 흐름을 보려고, 2주 합계를 주별 예약으로 쪼갰습니다. | 2주 합계 → 주별 예약, 새 축과 단위 표시 |
| 1:01–1:07 | 두 선은 완전히 같지는 않지만, 이전에는 대체로 비슷한 흐름을 보입니다. | 서로 같지 않은 사전 6주 두 선을 순서대로 그림 |
| 1:07–1:13 | 사전 추세는 평행추세 가정의 근거일 뿐, 증명은 아닙니다. | 평행추세의 근거 ≠ 증명 주의 문구 |
| 1:13–1:17 | 매장 특성과 같은 시기의 다른 변화도 따져야 합니다. | 매장 특성 / 다른 변화 확인 문구 |
| 1:17–1:26 | 대조군의 증가분을 적용하면, 기획전이 없었을 때 참여 매장의 2주 예약은 약 1만 1천 건입니다. | 주별 대조군 진행 2주, 노란 반사실 선, 2주 약 11,000건 |
| 1:26–1:32 | 실제 1만 2천 건과의 차이, 1천 건이 기획전 순증분의 추정치입니다. | 실제 선, 노란 선과 사이의 붉은 영역, 2주 순증분 1,000건 |
| 1:32–1:37 | 주별 그림의 500건씩 두 번을 합한, 2주 전체 효과입니다. | 붉은 영역 각각 +500 표시 |
| 1:37–1:44 | 계산도 같습니다. 참여 매장의 전후 증가분 2천 건에서 대조군의 1천 건을 뺍니다. | (12,000 − 10,000) − (9,000 − 8,000) = 1,000건 |
| 1:44–1:47 | 이것을 이중차분법, 디아이디라고 합니다. | DID / 이중차분법 이름 표시 |
| 1:47–1:53 | 예약 증가와 기획전 효과는 다릅니다. 그래서 인과추론이 필요합니다. | 예약 증가 ≠ 기획전 효과, 과제의 Why로 마무리 |

순증분 1,000건은 대조군 추세를 적용한 교육용 DID 추정치다. 사전 추세 그림은 평행추세 가정을 증명하지 않는다.
